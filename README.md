# Ozark Riichi Club Website
A multiuse website for the Ozark Riichi Club

## Our Purpose
ORC (Ozark Riichi Club) is dedicated to playing, teaching, and growing interest in Japanese-style (Riichi) Mahjong in Fayetteville, Springdale, Bentonville, Rogers, Siloam Springs, and surrounding towns. We welcome new beginners, experienced competitors, and those who are accustomed to different styles of mahjong!

## Using The Website
Using the website is as easy as visiting https://www.orcmahjong.com
